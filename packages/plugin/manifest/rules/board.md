# Board-Regel (AI-Harness)

- Tickets, Board, Kanban, Spalten, Backlog, Planung, Fragen, Notizen und IDs wie `ARC-0042` oder `ARC-F0001` meinen immer das AI-Harness-Board: Befehle über `harness board …`, Details im Skill `ai-harness:board`, Fragen über `ai-harness:board-question`.
- Nie ein altes Kanban (Befehl `kanban`, IDs `TCK-…`), nie GitHub- oder GitLab-Issues. Azure-DevOps-Work-Items nur lesen und nur auf ausdrückliche Bitte.
- Ein Repo arbeitet auf dem Board seines Repo-Pfads; Zuordnung mit `harness board boards repo <id> <pfad>` (Pfad = Hauptordner des Repos).
